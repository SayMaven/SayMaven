# About Me

Saat ini aku masih belajar lebih dalam tentang Data Science, Data Engineering, dan AI frameworks.

## Keahlian & Proyek Pekerjaan
- **Full-Stack Developer**: Berpengalaman dengan bahasa pemrograman seperti TypeScript, Python, Rust, dan Go. Saat ini sedang aktif mengembangkan platform web dan bekerja sebagai networking server.
- **Ilustrator Digital**: Fokus menciptakan seni karakter bergaya anime melalui platform seperti Pixiv dan Fanbox(Aku bisa bikin gambar tradisional maupun digital manual, ataupun gambar ai).
- **Modifikasi & Pemeliharaan Hardware**: Cukup andal dalam melakukan perbaikan komponen elektronik, hingga memodifikasinya sesuai kebutuhan.

## Hobi & Minat
- **Dunia Audiophile**: Sangat mengutamakan kualitas audio lossless dan penggemar IEM seperti Moondrop Blessing 3, Tanchjim Nora.
- **Gaming**: Menikmati rhythm game seperti Osu!mania, Project Sekai, dan BanG Dream!.
- **Generative AI**: Memanfaatkan dan memodifikasi software seperti Stable Diffusion dan ComfyUI dengan parameter yang spesifik.
- **Musik**: Penggemar berat J-Pop dan musik folk Jepang (khususnya penyanyi Yu Takahashi). Mahir bermain keyboard piano serta alat musik lain seperti gitar dan violin.
